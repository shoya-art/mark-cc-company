# 品質チェック報告形式

次の順序で報告する。

## 1. 判定

    判定: PASS / REVISE / BLOCK
    総合点: 00 / 100
    公開可否: 公開可能 / 修正後に再確認

CTA履歴や比較対象がなく一部を判定できない場合は、総合点を「参考点」と明記する。

## 2. 重大違反

重大違反がない場合は「なし」。ある場合は、原文を短く引用して一件ずつ書く。

    - 対象: 追いコメント②
      原文: 「…」
      違反: ①の未完部分を一文目で回収していない
      影響: 読者が話題のつながりを理解できない
      最小修正: 「それは、〜することです。」

## 3. パーツ別採点

| パーツ | 点数 | 判定 | 主な理由 |
|---|---:|---|---|
| 親投稿 | /20 | OK/要修正 | |
| 追いコメント① | /20 | OK/要修正 | |
| 追いコメント② | /20 | OK/要修正 | |
| 最終コメント | /20 | OK/要修正 | |
| チェーン全体 | /20 | OK/要修正 | |

## 4. 接続チェック

各接続で、前の末尾と次の冒頭を並べる。

    親 → ①: OK / NG
    末尾: 「でも、実は…↓」
    冒頭: 「まだ彼を諦めなくていいんです。」
    理由: 希望を即回収できている

## 5. CTAチェック

- CTA種別
- 本文からの接続
- 行動数
- CTA後の余計な文章
- 履歴がある場合は連投と20〜30%目安

## 6. 修正優先順位

最大3件に絞り、重大な順に並べる。

1. 公開を止める問題
2. 理解を妨げる問題
3. 温度感やジローらしさを弱める問題

全文修正を求められていない限り、最後に完成稿を付けない。
