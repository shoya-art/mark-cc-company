# Threads投稿チェーンを品質検査する

4つの文章を別々に採点した後、接続を一本のチェーンとして検査する。印象だけで合格させず、原文を根拠に判定する。

## 必ず読むルール

検査対象に応じて、次の作成スキルを正本として読む。

1. 親投稿: [../write-threads-parent-post/SKILL.md](../write-threads-parent-post/SKILL.md) と同スキルの references/
2. 追いコメント①: [../write-threads-reply-one/SKILL.md](../write-threads-reply-one/SKILL.md)
3. 追いコメント②: [../write-threads-reply-two/SKILL.md](../write-threads-reply-two/SKILL.md)
4. 最終コメント: [../write-threads-final-reply/SKILL.md](../write-threads-final-reply/SKILL.md) と同スキルの references/

重大違反と採点基準は [references/quality-gates.md](references/quality-gates.md) を読む。報告時は [references/report-format.md](references/report-format.md) に従う。

正本とこのスキルが矛盾する場合は、各作成スキルの新しいルールを優先する。

## 必要な入力

- 親投稿
- 追いコメント①
- 追いコメント②
- 最終コメント
- 可能なら直近14投稿のCTA履歴
- コピー類似性も調べる場合は比較対象の投稿

4パーツの一部がない場合は推測で補わず、欠落として不合格にする。CTA履歴がない場合、文章自体は検査するが、頻度と連投は「判定不能」と明記する。

## 検査手順

### 1. 機械条件を確認する

- 4パーツが揃っているか
- 各パーツが1〜500文字か
- 空のコメントがないか
- 親投稿以外が直前の投稿への返信として並んでいるか

文字数は改行を含む実際の文字列で数える。目測しない。

### 2. 各パーツを検査する

各作成スキルの順番、禁止事項、出力前チェックを一項目ずつ照合する。

- 親投稿は状況、悲観への共感、答えを伏せた反転だけか
- ①は希望を先に明言し、男性心理を簡潔に説明してNG行動の直前で切ったか
- ②はNG行動を一文目で回収し、行動、彼の受け取り方、逆の行動、希望を一直線につないだか
- 最終は②を端的に回収し、彼に見える変化、彼の期待、必要に応じた共感、CTAを自然につないだか

「内容が良い」だけで順序違反を許容しない。

### 3. 接続を検査する

次の3組について、前の末尾と次の冒頭を並べる。

1. 親投稿 → ①
2. ① → ②
3. ② → 最終

それぞれを次の観点で判定する。

- 次の一文目が直前の未完部分へ答えているか
- 新しい話題へ飛んでいないか
- 同じ説明を繰り返していないか
- 読者が途中で意味を補わなくても理解できるか
- 次を読む理由が残っているか

### 4. ジローのスタンスを検査する

- 読者を応援し、一緒に進む立場か
- 読者の意図や人格を「重い」「依存」などと決めつけていないか
- どんな状況にも可能性を残しつつ、復縁を保証していないか
- 彼の気持ちを事実として断定せず、「ことがある」など適切な幅を残したか
- 抽象語ではなく、読者や彼の心の声が想像できるか
- 「自己肯定感」を毎回直接使わず、生活や関係性の言葉へ変換したか

### 5. CTAを検査する

- 本文からCTAへ論理と感情がつながっているか
- CTA前の悩みが最大2つか
- 求める行動が一つだけか
- CTAの後に余計な一文がないか
- 直近履歴がある場合、同じCTA種別を連続使用していないか
- 固定投稿、プロフィール、LPへの直接誘導が全体の20〜30%程度か

誘導がない投稿を欠陥扱いしない。信頼形成、伴走、希望だけの締めも正しい選択肢とする。

### 6. 合否を決める

- PASS: 重大違反なし、85点以上
- REVISE: 重大違反はないが、84点以下または改善必須項目あり
- BLOCK: 重大違反が1つ以上あり、公開不可

高得点でも重大違反があれば BLOCK にする。

## 修正時の扱い

品質検査だけを求められた場合、全文を勝手に書き換えない。違反箇所、理由、最小修正案を示す。

修正版も求められた場合は、合格している部分を保持し、失格箇所だけを直す。修正後に同じ検査をもう一度実行し、最終判定を出す。

## 出力

[references/report-format.md](references/report-format.md) の順序で、簡潔かつ具体的に報告する。「なんとなく弱い」ではなく、該当する原文と破っているルールを対応させる。
