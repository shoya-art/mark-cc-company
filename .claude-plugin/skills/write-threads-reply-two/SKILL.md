# 追いコメント②を書く

①で予告したNG行動を回収し、行動から復縁可能性までを一直線につなぐ。読者の意図や人格を評価しない。

## 入力

- 承認済みの親投稿
- 承認済みの追いコメント①
- ①の最後で予告したNG行動
- 彼がその行動をどう受け取るか
- 反対の行動で彼に起きる変化
- 最終コメントで回収するテーマ

親投稿と①は書き換えない。

## スマホ改行

- 140〜220文字を目安とし、240文字以内にする
- 1行18文字前後、最大22文字にする
- 1ブロックを最大3行にする
- 意味が変わる場所に空行を1行入れる
- 心の声を並べすぎず、最大2つに絞る

## 構成

次の順番を守る。

1. ①の未完部分を一文目で回収する
2. 実際に起こりやすい言葉・行動を示す
3. 彼の受け取り方を心の声で示す
4. 彼がさらに離れたくなる理由を示す
5. 反対の行動を伝える
6. 彼の中で起こる変化を具体的に描く
7. 復縁の可能性へつなげる
8. 最終コメントの核心直前で切る

## ①を即回収する

最初の一文で答える。

```text
それは、彼の気持ちを変えようとして
連絡を続けることです。
```

「その行動とは何かというと」などの前置きは入れない。

## 行動を具体化する

読者の意図を推測せず、実際の言葉や行動だけを書く。

```text
「もう困らせないから」
「変わるから見ていてほしい」
「好きでいるだけならいい？」
```

禁止：

- 「あなたは彼を安心させたいんだよね」
- 「あなたは不安だから追っている」
- 読者を「重い」「依存している」と評価する

## 彼の反応を一直線に書く

一文一意味で、原因と結果を並べる。

```text
こう言われるほど彼は、
「また答えを求められる」
と感じて、さらに離れたくなります。
```

抽象語だけで済ませない。

- 悪い例：「彼の警戒心が強まります」
- 良い例：「また答えを求められる」と感じます

## 反対の行動と変化を書く

行動の意味を彼の心の声で説明する。

```text
逆に連絡を止めると、
彼は「もう追われないんだ」と安心できます。

そのとき初めて、
楽しかった記憶を
思い出す余裕が生まれます。
```

「距離を取る」「余白を作る」だけで終わらず、彼の中で何が変わるのかを書く。

## 可能性へつなげる

```text
ここから、復縁の可能性が動き始めます。
```

行動を制限するだけで終えず、必ず希望へ戻す。

## 最終コメントへ切る

ジローの中心テーマへつなぐ場合は、自己肯定感の直前で切る。

```text
彼にもう一度「会いたい」と
思わせるために必要なのが…↓
```

自己肯定感という答えは②で出さない。

## 完成例

```text
それは、彼の気持ちを変えようと
連絡を続けることです。

「ちゃんと話したい」
「一度だけ会ってほしい」

こう送るほど彼は、
「また答えを求められる」
と感じて、さらに離れたくなります。

逆に連絡を止めると、

「もう追われないんだ」

と初めて息ができます。

その時にようやく、
楽しかった記憶を思い出せます。

ここから復縁の可能性が
動き始めるんです。

彼にもう一度「会いたい」と
思わせるために必要なのが…↓
```

## 出力前チェック

- ①の未完部分へ一文目で答えたか
- 読者の意図や人格を決めつけていないか
- 一文に一つの意味だけがあるか
- 彼の反応を心の声で書いたか
- 反対の行動が必要な理由をイメージできるか
- 復縁の希望へ戻したか
- 最終コメントの答えを先に出していないか
- 22文字を超える行や4行以上のブロックがないか

完成した追いコメント②だけを出力する。
