# ジローのThreads完全版チェーンを作る

既存の各作成スキルを順番に使い、一つの設計情報を最後まで共有する。個別スキルのルールを複製せず、このスキルは工程、接続、品質ゲートを統括する。

## 絶対原則

1. **設計を先に固定する。** 各パーツを別々に考えると、男性心理や結論が途中で変わるため。
2. **直前の未完部分を次の一文目で回収する。** 読者に意味を補わせる接続は離脱を生むため。
3. **合格部分を作り直さない。** 修正のたびに別の箇所が崩れるのを防ぐため。
4. **品質点より重大違反を優先する。** 高得点でも、答えの先出しやCTA後の追記があれば公開できないため。
5. **読者へ希望を渡すが、結果は保証しない。** ジローの伴走姿勢と信頼性を両立するため。

## 使用範囲

次の場合に全工程を実行する。

- 新しいThreads投稿チェーンをゼロから作る
- 4パーツを一つの流れとして作り直す
- 既存チェーンの話題の飛びや区切りを修正する
- 自動投稿用に公開可能な完成稿を作る
- 個別スキルのルールを統合して最終確認する

親投稿だけなら [../write-threads-parent-post/SKILL.md](../write-threads-parent-post/SKILL.md)、①だけなら [../write-threads-reply-one/SKILL.md](../write-threads-reply-one/SKILL.md)、②だけなら [../write-threads-reply-two/SKILL.md](../write-threads-reply-two/SKILL.md)、最終だけなら [../write-threads-final-reply/SKILL.md](../write-threads-final-reply/SKILL.md) を使う。検査だけなら [../check-threads-reply-chain/SKILL.md](../check-threads-reply-chain/SKILL.md) を使う。

## 必ず読む資料

- 共通設計の項目と選び方: [references/chain-blueprint.md](references/chain-blueprint.md)
- 3つの接続契約: [references/transition-contracts.md](references/transition-contracts.md)
- 完成時の出力形式: [references/output-format.md](references/output-format.md)

## Sequential Pipeline

途中まで承認済みの文章がある場合、その文章を保持し、次の未完了フェーズから開始する。ただし共通設計と直前接続が不明ならPhase 1へ戻る。

### Phase 1: 共通設計を固定する

**Entry:** 投稿テーマ、読者の状況、または元ネタのいずれかがある。

**Actions:**

1. [references/chain-blueprint.md](references/chain-blueprint.md) の8項目を一つずつ決める。
2. 一投稿では一つの状況、一つの男性心理、一つのNG行動、一つの変化に絞る。
3. 直近14投稿があれば、テーマ、冒頭、区切り、CTAの重複を確認する。
4. 情報が不足しても安全に推定できる場合は仮説として補う。読者の事実や彼の断定が必要な場合だけ確認する。

**Exit:** 親投稿から最終コメントまで変更しない共通設計8項目が揃っている。

### Phase 2: 親投稿を作る

**Entry:** Phase 1の共通設計が完成している。

**Actions:**

1. [../write-threads-parent-post/SKILL.md](../write-threads-parent-post/SKILL.md) と同スキルの references/ を読む。
2. 具体的状況、悲観への共感、未完の反転だけを書く。
3. ①で渡す希望や理由を親投稿から削る。
4. 親投稿の末尾と①の予定冒頭を [references/transition-contracts.md](references/transition-contracts.md) で仮確認する。

**Exit:** 40〜120文字を目安とし、答えを出さず、①を読まないと意味が完結しない親投稿がある。

### Phase 3: 追いコメント①を作る

**Entry:** Phase 2の親投稿末尾と、共通設計の「①で渡す希望」「彼の心理」がある。

**Actions:**

1. [../write-threads-reply-one/SKILL.md](../write-threads-reply-one/SKILL.md) を読む。
2. 一文目から希望へ反転し、「なぜなら」で親投稿に合う男性心理を説明する。
3. 現在の拒絶と二人の未来を分ける。
4. ②で扱うNG行動の直前で切る。
5. 親→①の接続を検査し、意味がずれる場合は①の冒頭だけを直す。

**Exit:** 親投稿の問いを即回収し、読者へ希望を渡し、②の一文目で答えられる未完部分がある。

### Phase 4: 追いコメント②を作る

**Entry:** Phase 3の未完部分と、共通設計の「NG行動」「逆の行動」「彼に起きる変化」がある。

**Actions:**

1. [../write-threads-reply-two/SKILL.md](../write-threads-reply-two/SKILL.md) を読む。
2. 一文目でNG行動を即回収する。
3. 行動、彼の受け取り方、離れたくなる理由、逆の行動、彼の変化、希望の順に書く。
4. 最終コメントで扱う女性像や変化の直前で切る。
5. ①→②の接続を検査し、意味がずれる場合は②の冒頭だけを直す。

**Exit:** ①の問いへ答え、行動から彼の変化まで一直線につながり、最終の一文目で答えられる未完部分がある。

### Phase 5: 最終コメントを作る

**Entry:** Phase 4の未完部分と、共通設計の「彼に見せたい変化」「CTA種別」がある。

**Actions:**

1. [../write-threads-final-reply/SKILL.md](../write-threads-final-reply/SKILL.md) と同スキルの references/ を読む。
2. 冒頭1〜2文で②の未完部分を回収する。
3. 自己肯定感という概念を、彼に見える具体的な一変化へ翻訳する。
4. 彼が抱く前向きな期待を心の声で示す。
5. CTAを使う場合は、本文から自然につなぎ、一つの行動だけを求め、CTAで終了する。
6. ②→最終の接続を検査する。

**Exit:** 新しい論点を増やさず、希望とジローの温かさを残して完結する最終コメントがある。

### Phase 6: 品質ゲートと部分修正

**Entry:** 4パーツがすべて揃っている。

**Actions:**

1. [../check-threads-reply-chain/SKILL.md](../check-threads-reply-chain/SKILL.md) と同スキルの references/ を読む。
2. 4パーツ、3接続、ジローのスタンス、CTA、各500文字以内を検査する。
3. PASSならPhase 7へ進む。
4. REVISEまたはBLOCKなら、指摘されたパーツまたは接続だけを修正する。
5. 同じ品質検査を再実行する。修正ループは最大2回にする。
6. 2回修正してもBLOCKなら、公開可能と表示せず、残る違反を報告する。

**Exit:** PASS、または修正上限到達と残存違反が明確になっている。

### Phase 7: 完成稿を出力する

**Entry:** Phase 6がPASSである。

**Actions:**

1. [references/output-format.md](references/output-format.md) に従う。
2. 内部の共通設計や修正履歴は、求められない限り出さない。
3. 自動投稿用の形式指定がある場合は、そのマーカーを優先する。

**Exit:** 順番の明確な4パーツと品質判定があり、そのまま確認または投稿処理へ渡せる。

## 途中から再開する場合

| 既存の成果物 | 開始フェーズ |
|---|---|
| テーマだけ | Phase 1 |
| 共通設計あり | Phase 2 |
| 承認済み親投稿あり | Phase 3 |
| 親投稿と承認済み①あり | Phase 4 |
| 親投稿、①、承認済み②あり | Phase 5 |
| 4パーツあり | Phase 6 |

承認済み部分を変更する必要が出た場合は、変更理由と影響する後続パーツを先に示す。

## 拒否する近道

- 各パーツを独立生成して最後に並べる
- 親投稿で希望まで言ってしまう
- 接続の違和感を「読めば分かる」で通す
- 高得点を理由に重大違反を無視する
- 品質修正のたびに4パーツ全部を書き直す
- CTAが弱いという理由だけで毎回固定投稿へ誘導する

## 成功条件

- 共通設計8項目が4パーツで一貫している
- 親→①、①→②、②→最終がすべて即回収される
- 読者を否定せず、復縁の希望を残している
- 彼の心理が分かりやすく、断定しすぎていない
- CTAが本文と履歴に合い、一つだけである
- 各パーツが500文字以内である
- 品質ゲートがPASSである
