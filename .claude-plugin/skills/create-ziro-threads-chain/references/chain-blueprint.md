# 共通設計シート

生成前に次の8項目を固定し、4パーツすべてへ渡す。

| 項目 | 決める内容 | 制約 |
|---|---|---|
| 1. 読者の具体的状況 | 彼の言葉、LINE、ブロック、新しい彼女など | 一つだけ |
| 2. 読者が恐れる結論 | 「もう復縁は無理」「忘れられた」など | 読者を否定しない |
| 3. ①で渡す希望 | 「まだ諦めなくていい」など | 保証しない |
| 4. 彼の心理仮説 | 今すぐ関わる怖さ、決断を変えたくない等 | 一つを主軸にし断定しない |
| 5. ②で扱うNG行動 | 連絡を続ける、答えを迫る等 | 一つだけ |
| 6. 逆の行動と変化 | 連絡を止める→追われない安心等 | 原因と結果を直結 |
| 7. 最終で見せる変化 | 笑顔、落ち着いた話し方、自分の時間等 | 彼から確認できる一変化 |
| 8. CTA種別 | 固定投稿、伴走、孤独解消、希望、プロフィール、コメント | 一つだけ |

## 設計例

| 項目 | 内容 |
|---|---|
| 読者の状況 | 「連絡しないで」と強く拒絶された |
| 恐れる結論 | ここまで言われたら復縁は無理 |
| ①の希望 | まだ彼を諦めなくてよい可能性がある |
| 彼の心理 | 今すぐ答えや関係を求められることを避けたい |
| NG行動 | 気持ちを変えようとして連絡を続ける |
| 逆の行動と変化 | 連絡を止めると追われない安心が生まれる |
| 見せる変化 | 彼以外の時間も楽しみ、落ち着いて話せる |
| CTA | 固定投稿から相談 |

## 一貫性テスト

- ①の男性心理は親投稿の状況を説明しているか
- ②のNG行動は①の男性心理を悪化させる行動か
- ②の逆の行動はその心理を和らげるか
- 最終の変化は②で生まれた余裕の先にあるか
- CTAは最終で代弁した悩みへの次の一歩か

一つでも「いいえ」なら、文章を書く前に設計を修正する。
