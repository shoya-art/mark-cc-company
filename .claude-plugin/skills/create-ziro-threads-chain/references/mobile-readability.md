# スマホで読みやすい改行

Threadsのスマホ表示で、語尾だけが次の行へ落ちない文章にする。

## 必須基準

- 1行は18文字前後を目安にし、22文字以内にする
- 一つの意味を1〜2行で伝える
- 一つのブロックは最大3行にする
- 意味が変わる場所には空行を1行入れる
- 空行を2行以上連続させない
- 文の途中ではなく、意味の切れ目で改行する
- 句読点を増やして長文をつながない

## 文字数の目安

| パーツ | 目安 | 上限 |
|---|---:|---:|
| 親投稿 | 40〜90文字 | 110文字 |
| 追いコメント① | 140〜220文字 | 240文字 |
| 追いコメント② | 140〜220文字 | 240文字 |
| 最終コメント | 160〜240文字 | 260文字 |

改行も文字数に含める。内容を詰め込むより、一つの説明を削る。

## 読みやすい例

    復縁したい。
    でも、連絡したら
    もっと嫌われそう…

    何もしなかったら
    そのまま忘れられそう…

    そんな時でも…↓

より短くできる場合は次を優先する。

    復縁したい。
    でも、連絡したらもっと嫌われそう…

    何もしなかったら
    そのまま忘れられていきそう…

    そんな時でも…↓

## 避ける形

    何もしなければ、そのまま忘れられていく気がする。

理由: スマホ側の自動折り返しで「る。」だけが次行へ落ちやすい。

    どっちに進めばいいか、分からなくなってきたよね。

理由: 一文に迷いと共感を詰めており、視線が止まりにくい。

次のように短くする。

    どちらを選んでも怖くて、
    分からなくなるよね。

## 最終確認

各パーツをスマホ幅で読むつもりで確認する。

1. 22文字を超える行がない
2. 4行以上続くブロックがない
3. 語尾だけの行がない
4. 同じ意味を別表現で繰り返していない
5. 一画面で要点を拾える
