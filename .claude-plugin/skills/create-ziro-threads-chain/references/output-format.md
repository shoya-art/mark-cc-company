# 完成稿の出力形式

## 通常確認用

次の順番で出す。

    【親投稿】
    本文

    【追いコメント①】
    本文

    【追いコメント②】
    本文

    【最終コメント】
    本文

    【品質判定】
    PASS
    00 / 100

品質判定の詳細は、ユーザーが求めた場合またはREVISE/BLOCKの場合だけ付ける。

## 自動投稿用

呼び出し側がマーカー形式を指定した場合、その形式を厳守する。マーカーの中へ見出し、採点理由、設計情報を混ぜない。

## 出力しないもの

- 共通設計シート
- 各スキルを実行したという説明
- 修正ループの履歴
- 代替案
- 公開済み本文への無断変更

これらは求められた場合だけ出す。
