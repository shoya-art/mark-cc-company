# 接続契約

前の末尾を「問い」、次の冒頭を「答え」として一対一で対応させる。

## 親投稿 → 追いコメント①

親投稿の役割は悲観を受け止めて反転直前で止めること。①の最初は説明ではなく希望を渡す。

    親末尾: でも、実は…↓
    ①冒頭: まだ彼を諦めなくていいんです。復縁できる可能性はあります。

禁止:

- ①を「彼がこう言う理由は」から始め、希望を後回しにする
- 親投稿で「可能性はあります」まで先に言う

## 追いコメント① → 追いコメント②

①の役割はNG行動の存在だけを予告すること。②の一文目はその行動名を答える。

    ①末尾: ただし、ここで多くの女性がしてしまう、復縁を遠ざける行動が…↓
    ②冒頭: それは、彼の気持ちを変えようとして連絡を続けることです。

禁止:

- ②を共感や背景説明から始める
- ①でNG行動の答えを出す

## 追いコメント② → 最終コメント

②の役割は彼にもう一度会いたいと思わせるための必要条件を予告すること。最終は抽象語ではなく具体的な変化を答える。

    ②末尾: そして彼にもう一度「会いたい」と思わせるために必要になるのが…↓
    最終冒頭: 必要なのは、彼以外の時間も楽しめるようになること。

禁止:

- 「自己肯定感です」だけで回収する
- 長い前置きを挟む
- ②と関係のない新しい復縁テクニックへ移る

## 5秒テスト

各接続を二文だけ並べ、5秒で次を確認する。

1. 何への答えか分かる
2. 一文目で答えている
3. 同じ言葉を繰り返すだけではない
4. 前後の因果関係がある

一つでも満たさなければ、後ろのパーツの冒頭を優先して直す。承認済みの前パーツは必要がない限り変更しない。
