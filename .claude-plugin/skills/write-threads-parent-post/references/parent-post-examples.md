# 親投稿の完成例

すべて親投稿だけで完結させず、答えは追いコメント①へ残す。

## 強く拒絶された

```text
「復縁は考えられない」
「もう好きじゃない」
「連絡しないで」

ここまで言われたら、復縁は無理だと思うよね。

でも、実は…↓
```

## 追いLINEをした

```text
何通も追いLINEを送って、
最後は既読もつかなくなった。

ここまでしたら、もう取り返せないと思うよね。

でも、本当に見るべきなのは…↓
```

## 新しい彼女がいる

```text
元彼に新しい彼女ができた。

それを知ったら、
もう自分の入る場所はないと思うよね。

でも、実は…↓
```

## ブロックされた

```text
LINEもInstagramもブロックされた。

連絡手段が全部なくなったら、
もう復縁できないと思うよね。

それでも可能性が残っている理由は…↓
```

## 冷却期間中に連絡がない

```text
3か月連絡を我慢したのに、
彼からは何も来ない。

ここまで待っても動かないなら、
もう忘れられたと思うよね。

でも、実は…↓
```

## 冷たい返信しか来ない

```text
勇気を出してLINEしたのに、
返ってきたのは「うん」「了解」だけ。

こんなに冷たかったら、
もう気持ちはないと思うよね。

ただ、ここで勘違いしてほしくないのが…↓
```

## 禁止例

```text
「復縁は考えられない」
「もう好きじゃない」
「連絡しないで」

ここまで言われたら、復縁は無理だと思うよね。

でも、強く拒絶された状態から復縁する人もいる。
その人たちには共通点があります。
```

理由：親投稿で希望と説明を出しており、追いコメント①を開く必要が弱くなる。
