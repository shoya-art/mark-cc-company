# 親投稿の区切り設計

## 最重要原則

親投稿は説明しない。読者の状況と悲観的な結論だけを見せ、答えの直前で止める。

```text
具体的な状況
↓
読者の悲観的な結論
↓
短い反転
↓
追いコメント①で即回収
```

## 標準形

```text
「復縁は考えられない」
「もう好きじゃない」
「連絡しないで」

ここまで言われたら、復縁は無理だと思うよね。

でも、実は…↓
```

「でも、実は」の中身を親投稿に書かない。

## 切り方の種類

### 1. 単純反転

最も短く、幅広い状況で使う。

```text
でも、実は…↓
```

### 2. 見る場所の反転

読者が彼の言葉や行動だけを見ているときに使う。

```text
でも、本当に見るべきなのは…↓
```

### 3. 誤解の反転

広く信じられている復縁常識を覆すときに使う。

```text
ただ、ここで勘違いしてほしくないのが…↓
```

### 4. 可能性の理由

絶望的な状況に希望が残る理由を①で説明するときに使う。

```text
それでも復縁の可能性が残っている理由は…↓
```

### 5. 文の途中

短い物語や主張を、目的語や理由の直前で止める。

```text
復縁で本当に差がつくのは、
別れ際ではなく…↓
```

多用せず、文として自然に回収できる場合だけ使う。

## 弱い区切り

### 答えを先に出す

```text
でも、強く拒絶された状態から復縁する人もいます。
```

希望を得たため、①を開く必要が弱くなる。

### 完結した予告

```text
その人たちには、ある共通点があります。
```

興味は残るが、文章として完結しており推進力が弱い。

### 操作を説明する

```text
続きはコメントで説明します。
```

投稿の世界から読者を出してしまう。

### 抽象的に煽る

```text
衝撃の事実があります…↓
```

読者の具体的な不安と接続していない。

## 強度テスト

- 最後の反転より前に、希望や答えを出していないか
- ①の最初の2行を隠すと、答えが分からないか
- 読者が自分の状況だと一読で分かるか
- 反転文を削ると、ただの共感投稿になるか
- 反転の直後で完全に文章が終わっているか

一つでも満たさない場合は、親投稿から説明を削る。
