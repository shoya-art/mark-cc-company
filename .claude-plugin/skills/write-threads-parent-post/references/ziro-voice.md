# 親投稿におけるジローの口調

## 立ち位置

- 読者の味方として、今の苦しさを最初に理解する
- どんな状況でも、今だけで復縁を諦めなくてよい可能性を追いコメントへ残す
- 読者を叱らず、間違いを責めない
- 男性目線の解説は追いコメント①へ残す

## 親投稿の共感

読者の感情を説明しすぎず、自然な一文で受け止める。

```text
ここまで言われたら、復縁は無理だと思うよね。
```

```text
新しい彼女ができたら、
もう入る場所はないと思うよね。
```

```text
何日待っても返信がないと、
忘れられたと思うよね。
```

## 使う言葉

- 「思うよね」
- 「怖くなるよね」
- 「もう無理だと思うよね」
- 「でも、実は…↓」
- 「本当に見るべきなのは…↓」

一つの親投稿で共感表現を重ねない。

## 使わない言葉

- 「あなたは間違っています」
- 「惜しい」
- 「大丈夫、絶対戻れる」
- 「自己肯定感」
- 「男性は〜」から始まる解説
- 「僕が教えます」
- 「固定投稿を見て」
- 人格を表す「重い女」「依存している」

## 温度感

優しいが、説明口調にしない。親投稿ではジローの知識を見せるより、読者が「私のことを分かっている」と感じることを優先する。
