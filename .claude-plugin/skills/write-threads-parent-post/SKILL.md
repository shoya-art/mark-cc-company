# Threads親投稿を作る

親投稿の役割を「共感して、反転を予告し、追いコメントを開かせること」に限定する。男性心理、具体策、自己肯定感、CTAは追いコメントへ残す。

## 必ず読む資料

- 切り方を決めるときは [references/cut-points.md](references/cut-points.md) を読む。
- ジローの親投稿口調を確認するときは [references/ziro-voice.md](references/ziro-voice.md) を読む。
- 完成形を確認するときは [references/parent-post-examples.md](references/parent-post-examples.md) を読む。

## 入力

- 読者が置かれている具体的な状況
- 彼の実際の言葉または行動
- 読者が最も恐れている結論
- 追いコメント①で最初に渡す希望
- 最近の親投稿で使った冒頭と切り方

追いコメント①の答えを先に決めてから、親投稿ではその答えを隠す。

## 基本構造

次の3ブロックだけで作る。

1. 彼の言葉または読者の場面
2. 読者が出してしまう悲観的な結論への共感
3. 答えを伏せた短い反転

```text
「復縁は考えられない」
「もう好きじゃない」
「連絡しないで」

ここまで言われたら、復縁は無理だと思うよね。

でも、実は…↓
```

## 1. 状況を一目で分からせる

読者が「私のことだ」と判断できる具体的な言葉または場面を使う。

優先順位：

1. 彼に実際に言われる言葉
2. LINE、ブロック、SNS、再会などの具体的な出来事
3. 読者の頭に浮かぶ短い本音

「復縁で悩んでいる人へ」のような広い呼びかけから始めない。一つの投稿で一つの状況だけを扱う。

## 2. 読者の結論へ共感する

一文だけで受け止める。

```text
ここまで言われたら、復縁は無理だと思うよね。
```

否定、説教、励ましを入れない。「でも大丈夫」まで親投稿で言わない。

## 3. 答えの直前で切る

標準形は次を使う。

```text
でも、実は…↓
```

投稿履歴に応じて、同じ働きをする別の切り方へ変えてよい。

```text
でも、本当に見るべきなのは…↓
```

```text
ただ、ここで勘違いしてほしくないのが…↓
```

```text
それでも復縁の可能性が残っている理由は…↓
```

答え、理由、共通点、具体策は書かない。

## 親投稿に入れないもの

- 「強く拒絶された状態から関係が動く人もいる」などの答え
- 「その人たちには共通点がある」などの説明型予告
- 男性心理の解説
- 復縁方法やNG行動
- 自己肯定感や理想の女性像
- 実績、相談事例、CTA
- 「続きはコメントへ」という操作説明
- 長い背景説明

## 長さと文体

- 目安は40〜120文字
- 3ブロック、全体3〜8行程度を基本にする
- 一文一意味にする
- 話し言葉で書く
- 絵文字は原則使わない。必要でも1個まで
- 同じ冒頭文や反転文を連投しない
- 煽りだけにせず、読者が実際に抱える不安を使う

## 出力

完成した親投稿だけを出力する。見出し、解説、追いコメント案を付けない。

## 最終チェック

- 読者の状況が最初の3行以内に分かるか
- 一つの状況だけを扱っているか
- 読者の「もう無理」という結論を否定せず受け止めたか
- 親投稿で答えを一つも出していないか
- 最後が短い反転で未完になっているか
- 追いコメント①の最初を読まないと答えが分からないか
- 「でも、実は…↓」の後に余計な一文がないか
