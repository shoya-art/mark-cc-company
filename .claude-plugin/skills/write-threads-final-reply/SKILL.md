# Threads最終コメントを書く

追いコメント②から自然につなぎ、読者へ希望とジローの温かさを残して完結する。途中で新しい論点を増やさない。

## 必ず読む資料

- 自己肯定感の言い換えを選ぶときは [references/transformation-frames.md](references/transformation-frames.md) を読む。
- 締め方を選ぶときは [references/cta-endings.md](references/cta-endings.md) を読む。
- 文体と完成形を確認するときは [references/approved-example.md](references/approved-example.md) を読む。

## 入力

- 承認済みの親投稿
- 承認済みの追いコメント①と②
- ②の最後に残した未完の疑問
- 読者の状況
- 彼に見せたい変化
- 最近14投稿のCTA履歴
- 今回のCTA種別。指定がなければ履歴から選ぶ

親投稿、①、②は書き換えない。

## 構成

次の順番で書く。

1. ②の未完部分を端的に回収する
2. 彼に見える変化を一つだけ示す
3. 彼が抱く前向きな期待を心の声で示す
4. CTAを入れる場合は、読者が動けない理由を最大2つまで代弁する
5. 読者が本当に知りたいことを一つ言語化する
6. 一つのCTAで終了する

## ②を端的に回収する

自己肯定感という単語を原則使わず、行動や女性像へ翻訳する。

```text
必要なのは、
彼以外の時間も楽しめるようになること。
```

回収は1〜2文で終える。「難しく考えなくて大丈夫」などの前置きを入れない。

## 彼から見える変化を書く

抽象的な内面ではなく、彼が実際に確認できる変化を一つ選ぶ。

- 笑顔が増えた
- 落ち着いて話せるようになった
- 自分の時間を楽しんでいる
- 本音を責めずに伝えられる
- 彼の話を最後まで聞ける

続けて、彼の期待を2つ以内の心の声で示す。

```text
彼があなたの笑顔や落ち着いた話し方を見たとき、

「前より魅力的になったな」
「今なら、もう一度会ってみたいな」

と思うきっかけになるんです。
```

彼の行動を長い場面で描きすぎない。最終コメントでは変化と期待が伝わればよい。

## 読者の迷いへ寄り添う

CTAを入れる場合だけ、動けない理由を最大2つまで選ぶ。似た不安は一つへまとめる。

推奨する2つ：

1. 動くのも待つのも怖く、正解が分からない
2. 周囲に反対され、相談できる相手がいない

```text
彼を諦めたくないのに、
連絡したらもっと嫌われそう。
何もしなければ忘れられそう。

どちらを選べばいいか、分からなくなるよね。
```

読者の人格や意図を評価しない。「依存している」「重い」などのラベルを使わない。

## 本当に知りたいことを代弁する

```text
でも、あなたが知りたいのは
諦める方法じゃないと思う。

彼ともう一度向き合うために、
今から何ができるかを知りたいんだよね。
```

ジローが分かってくれていると感じる部分なので、省略しない。

## CTAで終了する

CTAは一つだけにする。固定投稿へ誘導する場合は、次のように終える。

```text
そんなときは、一人で抱え込まず
固定投稿からいつでも僕に話しに来てね。
```

CTAの後に、約束、希望、説明、別の行動を付け足さない。

## 長さと文体

- Threadsの1返信内に収める
- 目安は180〜350文字。必要な共感を削ってまで機械的に合わせない
- 一文一意味にする
- 一人称は「僕」
- 読者へ話しかける温かい口調にする
- 強い命令、説教、過剰な敬語を使わない
- 同じ語尾やCTAを連投しない

## 出力前チェック

- ②の未完部分へ最初に答えたか
- 「自己肯定感」を安易に使っていないか
- 彼が確認できる変化を一つに絞ったか
- 彼の心の声が期待を感じさせるか
- CTA前の悩みが2つ以内か
- 読者が本当に知りたいことを代弁したか
- 最近の投稿と同じCTAではないか
- お願いする行動が一つだけか
- CTAで文章を終えたか

完成した最終コメントだけを出力する。
