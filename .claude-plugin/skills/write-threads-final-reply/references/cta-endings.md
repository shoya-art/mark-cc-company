# CTAの選択と分散

事業上の最終目的は、プロフィールまたは固定投稿のLPから公式LINEを追加してもらうこと。ただし、毎回直接誘導すると信頼を失うため、投稿ごとに締めの役割を変える。

## 選択ルール

- 最近14投稿と同じ文章を使わない
- 同じCTA種別を連続させない
- 一つの投稿で求める行動は一つだけにする
- 固定投稿・プロフィール・LPへの誘導は全体の20〜30%を目安にする
- 誘導しない投稿でも、ジローへの信頼が積み上がる締めにする
- 投稿本文の最後に残った感情からCTAを選ぶ

## 1. 固定投稿から相談

深い悩みがあり、個別の状況判断を求めている投稿に使う。

```text
そんなときは、一人で抱え込まず
固定投稿からいつでも僕に話しに来てね。
```

このCTAを使ったら、後に文章を追加しない。

## 2. 伴走

売り込みをせず、ジローと一緒に進む印象を残す。

```text
今すぐ答えを出さなくて大丈夫。
彼との未来を諦めず、一緒に進んでいこう。
```

## 3. 孤独をなくす

誰にも話せない読者を安心させる。

```text
一人で全部抱え込まなくて大丈夫。
あなたは一人じゃないよ。
```

## 4. 希望だけを残す

CTAを入れず、投稿内容を強く印象づける。

```text
今の状況だけで、二人の未来まで諦めなくて大丈夫だよ。
```

## 5. プロフィール・LP

復縁方法やロードマップを求める読者へ、短く案内する。

```text
彼との関係をここから立て直したい人へ。
プロフィールに、復縁までの進め方を置いています。
```

実際のリンク先にない内容を案内しない。

## 6. コメント

二択または一問だけにする。

```text
今、一番苦しいのは
「連絡できないこと」と「彼の気持ちが分からないこと」どっち？
```

## 固定投稿CTAへつなぐ共感

悩みは最大2つにする。

```text
彼を諦めたくないのに、
連絡したらもっと嫌われそう。
何もしなければ忘れられそう。

どちらを選べばいいか、分からなくなるよね。

友達に相談しても、
「もう諦めた方がいい」
「次の人を探しなよ」と言われる。
```

続けて、読者が求める答えを代弁する。

```text
でも、あなたが知りたいのは
諦める方法じゃないと思う。

彼ともう一度向き合うために、
今から何ができるかを知りたいんだよね。
```

最後に固定投稿CTAを置き、そこで終了する。
