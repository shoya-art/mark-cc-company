# 承認済み完成例

追いコメント②が次で終わった場合：

```text
そして彼にもう一度「会いたい」と思わせるために
必要になるのが…↓
```

最終コメント：

```text
必要なのは、
彼以外の時間も楽しめるようになること。

彼があなたの笑顔や落ち着いた話し方を見たとき、

「前より魅力的になったな」
「今なら、もう一度会ってみたいな」

と思うきっかけになるんです。

でも、

彼を諦めたくないのに、
連絡したらもっと嫌われそう。
何もしなければ忘れられそう。

どちらを選べばいいか、分からなくなるよね。

友達に相談しても、
「もう諦めた方がいい」
「次の人を探しなよ」と言われる。

でも、あなたが知りたいのは
諦める方法じゃないと思う。

彼ともう一度向き合うために、
今から何ができるかを知りたいんだよね。

そんなときは、一人で抱え込まず
固定投稿からいつでも僕に話しに来てね。
```

守る点：

- 冒頭の主張を端的にする
- 長い場面描写を入れない
- 彼から見える変化と期待を示す
- CTA前の悩みを2つに限定する
- 読者が欲しい答えを代弁する
- 固定投稿CTAで終了する
