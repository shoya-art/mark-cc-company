# 承認済み完成例

追いコメント②が次で終わった場合：

```text
彼にもう一度「会いたい」と
思わせるために必要なのが…↓
```

最終コメント：

```text
必要なのは、

彼を待つ時間も
自分の毎日を楽しめること。

彼があなたの笑顔や
落ち着いた話し方を見た時、

「前より魅力的になったな」
「また会ってみたいな」

と思うきっかけになるんです。

でも、

連絡したら嫌われそう。
何もしなければ忘れられそう。

どちらも怖くなるよね。

でも、知りたいのは
諦める方法じゃないと思う。

彼と向き合うために
今できることだよね。

そんなときは、一人で抱え込まず
固定投稿からいつでも僕に話しに来てね。
```

守る点：

- 冒頭の主張を端的にする
- 長い場面描写を入れない
- 彼から見える変化と期待を示す
- CTA前の悩みを2つ以内にする
- 読者が欲しい答えを代弁する
- 固定投稿CTAで終了する
- 1行22文字、1ブロック3行以内にする
