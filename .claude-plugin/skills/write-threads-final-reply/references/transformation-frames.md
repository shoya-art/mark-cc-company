# 自己肯定感を直接言わない変換表

「自己肯定感」は内部テーマとして扱い、読者が想像できる女性像や行動へ変換する。投稿の悩みに最も近い軸を一つだけ選ぶ。

## 1. 自分の時間

主張：

```text
必要なのは、
彼以外の時間も楽しめること。
```

彼に見える変化：自分の予定、仕事、友達との時間を楽しんでいる。

彼の期待：

```text
「前より明るくなったな」
「もう一度会ってみたいな」
```

## 2. 心の余裕

主張：

```text
必要なのは、
すぐに答えを出そうとしないこと。
```

彼に見える変化：返信を急かさず、落ち着いて会話できる。

彼の期待：

```text
「今なら安心して話せそうだな」
「前とは違うかもしれない」
```

## 3. 本音を伝える力

主張：

```text
必要なのは、
我慢せずに本音を伝えること。
```

彼に見える変化：泣くことを否定せず、責めない言葉で本音を伝える。

彼の期待：

```text
「ちゃんと話し合えそうだな」
「もう一度向き合ってみたいな」
```

## 4. 対等な関係

主張：

```text
必要なのは、
彼と同じくらい
自分の気持ちも大切にすること。
```

彼に見える変化：彼の顔色だけで決めず、自分の意見を落ち着いて伝える。

彼の期待：

```text
「前より自然に一緒にいられそうだな」
「今度は対等に向き合えそうだな」
```

## 5. 思いやりと言葉選び

主張：

```text
必要なのは、
彼の気持ちも考えて話すこと。
```

彼に見える変化：相手の話を聞き、否定や責めから会話を始めない。

彼の期待：

```text
「この子になら本音を話せそうだな」
「また一緒に過ごしたいな」
```

## 6. 自分への自信

主張：

```text
必要なのは、
彼の言葉だけで
自分の価値を決めないこと。
```

彼に見える変化：外見や仕事、好きなことを自分のために楽しんでいる。

彼の期待：

```text
「前より魅力的になったな」
「また会って話したいな」
```

## 7. 安定した明るさ

主張：

```text
必要なのは、
自分で安心できる時間を増やすこと。
```

彼に見える変化：彼の態度だけで一日中気分を変えず、自然に笑える。

彼の期待：

```text
「一緒にいると落ち着きそうだな」
「今ならまた近づけそうだな」
```

## 変換時の禁止事項

- 毎回「自立した女性」と書く
- 「感情を出さない」「泣かない女性」を理想にする
- 彼を上手に誘導する女性として描く
- 彼のためだけに変わるよう促す
- 複数の女性像を一度に詰め込む
