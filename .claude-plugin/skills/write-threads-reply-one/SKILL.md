# 追いコメント①を書く

親投稿で残した疑問を即座に回収し、読者へ希望を渡す。①では具体策や自己肯定感まで説明しない。

## 入力

- 承認済みの親投稿
- 読者が恐れている結論
- 彼の言葉または行動
- 今の彼に考えられる男性心理
- ②で説明するNG行動

親投稿は書き換えない。

## 構成

次の順番を守る。

1. 復縁の希望を最初に言い切る
2. 「なぜなら」で理由を始める
3. 彼の心の声を2〜3個示す
4. 現在の拒絶と二人の未来を分ける
5. ②で回収するNG行動の直前で切る

## 希望を言い切る

最初の2行で、読者が一番欲しい答えを渡す。

```text
まだ彼を諦めなくていいんです。
復縁できる可能性はあります。
```

状況に応じて「まだ可能性はあるんです」「復縁できる希望はあります」と変えてよい。

禁止：

- 「気持ちが完全にゼロとは限らない」
- 「可能性がないとは言えない」
- 結論を最後まで引っ張る
- 「絶対に復縁できます」と保証する

## 男性心理を説明する

希望の直後に「なぜなら」を置く。一文に一つの意味だけを書く。

```text
なぜなら、今の彼が拒絶しているのは
あなたとの未来ではなく、
「今すぐ関わること」だから。
```

続けて、彼の心の声を短く示す。

```text
「これ以上期待させたくない」
「また同じ関係になるのが怖い」
「自分の決断を変えたくない」
```

難しい心理用語を使わない。「彼は必ずこう思っている」と断定せず、「こう思って距離を取ることがあります」と書く。

## 希望へ戻す

男性心理を説明した後、現在と未来を分ける。

```text
だから今の拒絶だけで、
彼の気持ちも二人の未来も決まったわけではありません。
```

## ②へ切る

答えを説明せず、具体的なNG行動の直前で止める。

```text
ただし、ここで多くの女性がしてしまう
復縁を遠ざける行動が…↓
```

「続きは次へ」などの案内は書かない。

## 完成例

```text
まだ彼を諦めなくていいんです。
復縁できる可能性はあります。

なぜなら、今の彼が拒絶しているのは
あなたとの未来ではなく、
「今すぐ関わること」だから。

別れた直後の男性は、
気持ちが残っていても
「自分の決断を変えたくない」
「また同じ関係になるのが怖い」
と思って距離を取ることがあります。

だから今の拒絶だけで、
彼の気持ちも二人の未来も決まったわけではありません。

ただし、ここで多くの女性がしてしまう
復縁を遠ざける行動が…↓
```

## 出力前チェック

- 冒頭で希望を明言したか
- 「なぜなら」の後が親投稿の状況に合っているか
- 彼の心の声を読者がすぐ想像できるか
- 回りくどい二重否定がないか
- 具体策や自己肯定感を先に説明していないか
- 最後が②で回収できる未完の疑問か

完成した追いコメント①だけを出力する。
